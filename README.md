# 拯救废星 · M7 净化作战（Windows 试玩版）

一款 2D 像素风战斗 Roguelike。你从 4 名净化者中选一人，被传送进被病毒吞噬的废弃星球 M7，一路向下打穿污染网络——最后带走多少污染，决定你成为什么。


---

## 一、开始游戏

双击目录内的 **`Save_AbandonedStar.exe`** 即可启动。首次启动可能弹出安全提示，选择「更多信息 → 仍要运行」。

- 空间：约 32 MB
- 不需要安装 Unity 或任何运行库

退出后如需删除，直接删除整个文件夹即可，不写注册表、不留残留文件。

## 三、怎么玩

```
标题 → 开场剧情（点击逐幕推进）→ 选英雄 → 战斗 → 下一关 → 结局
```

- 一局共 **3 关**，每关 **8 间房**：起始房 → 战斗 / 商店 / 特殊房（随机）→ Boss
- 清空一间战斗房后，弹出**污染结算面板**：这一间的污染点由你决定怎么处理
  - **吸收** → 污染值上升，伤害与攻速变强
  - **净化** → 换成纯净能源，可在商店买武器与回血
  - **各半** → 两边都拿一点
- 污染值越高伤害越高（满值约 2.5 倍），但**结局会越走越暗**。想要最好的结局，就得靠装备与走位，一点污染都不沾。

**7 种结局**：完美救赎 / 纯净救赎 / 带菌救赎 / 堕落者 / 濒核者 / 新的核心 / 失踪（阵亡）。

## 五、已知问题

这是毕业设计的阶段版本，以下为已知未完成项，不是运行故障：

- **敌人与小怪多为矢量色块**（原型临时美术），只有 Boss 与英雄有正式立绘；背景与武器尚未出图
- **无逐帧动画**：玩家和小怪使用挤压/缩放的程序化动作，Boss 已有帧动画
- **没有难度选择页**，难度随关卡自动递增
- **「信号幽灵」的瞬移行为**未实现，目前按高速游走处理
- **最终大反派关（污染核心资格战）** 尚未接入，打完 3 关即结算
- 若画面出现黑边或比例异常，请确认显示器缩放不是非标准比例；游戏设计分辨率为 960×600，会按窗口等比缩放
